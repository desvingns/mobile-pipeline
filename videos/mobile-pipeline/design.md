# Mobile Pipeline visual identity

Concept: a calm workshop where one idea passes through distinct specialists.

Canvas 1920x1080. Warm paper #f6f5f0, ink #203c34, accent #285947,
lime #e5efac, muted #52634e. Human accent #886022, automation #3b6094,
artifact #75518d. Agent cards #fffefa. Use dark text on pale fills.

Locally bundled Onest variable font (Cyrillic and Latin, OFL). One family is
intentional: shared with the node-editor interface, where hierarchy comes from
size/weight. Headings 64–78px, roles 32px, explanations 25–30px, captions 32px.

Focal element: current role or task. Anchor: coordinator bar and chapter number.
Supporting detail: recipe phone mockup and result. Background: pale dot grid,
large chapter numeral, fixed route line. Keep captions below scene content.

Motion: measured SVG connector drawing, calm scale entrances, task packet
translation, progress strokes; simultaneous active cards only in research.
Do not invent real performance numbers or real agent telemetry.
