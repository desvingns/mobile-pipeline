# «Фабрика приложений» — the Mobile Pipeline film (HyperFrames 0.8.65)

A ~3-minute narrated Russian explainer, 1920×1080 / 30 fps, built as a HyperFrames project. Everything
visible is generated from `narration/narration.json` + hand-authored scene templates in `src/scenes/`.
Spec: `../docs/design-video.md` · brand: `../docs/brand.md` · intent: `BRIEF.md` · look: `design.md`.

Current build: **177.8 s**, 10 scenes, 53 caption groups, 20 SFX, 11 transitions (see `timing.json`).

## Layout

```
narration/narration.json      the words ([[cue]] markers, {shown|spoken}); words/<id>.json = TTS word timings
narration/voice.json          measured voice takes (durations, shared gain, loudness before/after)
src/scenes/<id>.html          scene templates (scene packs own the bodies) — contract: src/scenes/README.md
src/scenes/scenes.json        fields, transitions, HUD stations, «да» cues, snapshot beats, motion citations
src/layers/{captions,hud,wipes}.html   the three full-length layers (foundation-owned sources)
src/sfx.json                  SFX cues (whoosh at every cut is automatic)
src/runtime/helpers.js        window.MPV — seeded rng, finite loops, arrive/slam/press/bob/blink/count/type
src/partials/chars-bridge.cjs the site illustration kit (../assets/js/chars.js, belt.js) in a Node vm
scripts/                      the pipeline (below); scripts/lib/ shared helpers
assets/                       fonts, gsap, sfx (vendored), voice/*.wav, music/bed.wav — see assets/LICENSES.md
compositions/, index.html, timing.json, STORYBOARD.md   GENERATED — never edit by hand
../media/{mobile-pipeline.srt,.vtt, chapters.js, transcript.js}   GENERATED by the build for the site
```

## Rebuild (Git Bash, from this folder)

```bash
cd /d/Pet/mobile-pipeline/showcase/video
export PYTHONUTF8=1

# 0. third-party files (fonts, GSAP, SFX -> 48 kHz WAV) — idempotent
node scripts/vendor-assets.cjs

# 1. voice: edge-tts (cached by text hash; 3 concurrent, 4 retries) -> shared gain/limiter -> 48 kHz WAVs
./.venv/Scripts/python.exe scripts/generate-voice.py          # [--only s03-talk] [--force]
node scripts/process-voice.cjs

# 2. plan (writes timing.json, prints durations / words per second / cues)
node scripts/build-video.cjs --plan-only

# 3. music bed: Lyria take -> trim to total+0.5 s, fades, -20 LUFS (synth fallback when Lyria is missing)
node scripts/process-music.cjs                  # or: node scripts/synth-music.cjs && node scripts/process-music.cjs --source synth

# 4. assemble + carve the bed under the voice (carve MUST follow every build)
node scripts/build-video.cjs && node scripts/carve.cjs

# 5. gates
npx --yes hyperframes@0.8.65 lint
PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS=180000 npx --yes hyperframes@0.8.65 check --json --timeout 90000 > .hyperframes/check.json
PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS=180000 npx --yes hyperframes@0.8.65 snapshot \
  --at "$(node scripts/build-video.cjs --print-snapshots)" --no-end --describe false -o snapshots/qa

# 6. project QA tools (each prints one JSON line; reports land in .hyperframes/qa/)
node scripts/anim-audit.cjs            # choreography: reverts (render vs seek disagree), dead zones, late tweens
node scripts/seek-audit.cjs            # every scene played frame by frame vs jumped to: painted state must match
node scripts/preview-mix.cjs           # renderer-exact audio mix + BS.1770 loudness (voice / bed / SFX / mix)
node scripts/caption-qa.cjs            # caption lines / title-safe / band + karaoke word vs voice onset
node scripts/contact-sheet.cjs snapshots/qa   # tile snapshot frames into labelled sheets
```

`PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS` is needed because the page loads ~50 MB of WAV audio and the CLI's
default navigation budget is 10 s. `--describe false` keeps frames local (GEMINI key in env).

`check`'s `--caption-zone` / `--frame-check` gates only sample at their own `seek=` fractions (default: the
last frame), not at every `--at` time. For a real caption-band sweep pass one fraction per sample, e.g.
`--caption-zone "x0=0;y0=.741;x1=1;y1=.9;seek=<t1/177.8>,<t2/177.8>,…"` (caption groups carry
`data-layout-allow-caption-zone`, so only scene copy in y 800–972 is reported).

`anim-audit.cjs` replaces the skill's `animation-map.mjs`, which needs a one-off npm install of
`@hyperframes/producer`. A `revert` (an earlier tween on the same element and property outlives a later
one) must be fixed: the renderer plays frames in order, so the earlier tween drags the value back after the
later one completes, while snapshots and `check` (cold seeks) show the later value.

Scene packs working in parallel: `node scripts/build-video.cjs --only <sceneId>` rewrites only that
scene's composition; run the full build + carve once before lint/check.

## Render (only after the preview is approved)

```bash
node scripts/build-video.cjs && node scripts/carve.cjs      # the carve must be on the index.html you render
mkdir -p renders
PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS=180000 npx --yes hyperframes@0.8.65 render --quality delivery --fps 30 \
  --workers 4 --browser-timeout 180 --output renders/mobile-pipeline.mp4 2>&1 | tee renders/render.log
node scripts/verify-output.cjs --log renders/render.log
```

`verify-output.cjs` gates the file (H.264 High yuv420p 1920×1080 30 fps CFR, AAC 48 kHz stereo, duration =
plan ±0.1 s, +faststart (remuxes if needed), −16 ±1 LUFS, TP ≤ −1 dBTP, clean decode, no compile audio
warnings, fonts in the log) and then publishes `../media/mobile-pipeline.mp4`, `../media/poster.jpg`
(end card at total − 1.5 s) and refreshes `../media/chapters.js` with the probed duration.
`--no-publish` checks only.

## Audio facts (current build)

- Voice: ru-RU-SvetlanaNeural, rate +8 %, 161.7 s of takes; one shared gain +4.77 dB plus the same
  delay-compensated peak limiter (ceiling −2 dBFS) on every take → −16.2 LUFS, −1.7 dBTP.
- Bed: Lyria take, 178.3 s, −20.0 LUFS, −3.0 dBTP; carve strength 0.55 against group `voiceover`
  (4 bands, level floor −13.2 dB, 5 automation lanes). Measured mix (preview-mix.cjs): −16.5 LUFS,
  −1.6 dBTP; voice −16.1; bed ≈ −32 LUFS-M under speech, −22…−26 at the scene gaps.
- SFX: 48 kHz stereo WAV, peak-normalised to −3 dBFS, placed so each file's loudest 10 ms lands on its cue.

## Editing the words

Change `narration/narration.json`, then run steps 1–4. The build fails loudly if a template uses a cue
that no longer exists, if word timings are stale, or if a transition would land on a spoken word.
If the total goes above 180 s apply the trim plan in `narration.json` (`trimPlan`), never ffmpeg atempo.
